GTA 6 Clip Desk

A personal desktop app for macOS that turns long gameplay videos into short vertical clips.

What it does

  • Finds highlight moments in a video the user provides, using the audio track and an on-device transcript.
  • Cuts a 1080x1920 clip with captions and a short on-screen title.
  • Lets the user send a finished clip to their own TikTok account, either to their TikTok inbox to finish in the TikTok app, or as a post with the privacy level they pick.

How it uses TikTok

The app uses TikTok Login Kit so the user can connect their own account, and the Content Posting API to upload a clip the user has selected. Nothing is uploaded automatically: every upload starts with the user pressing a button for one specific clip, and the user can disconnect at any time.

Where it runs

The app runs entirely on the user's own computer. It has no online service, no user accounts of its own and no analytics.
